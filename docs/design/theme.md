# Theme: a journey together

| Element            | Meaning                                   |
| ------------------ | ----------------------------------------- |
| Globe              | The world and a shared future             |
| Compass            | Direction and partnership                 |
| Airplane           | The journey of marriage                   |
| Route              | The path Fritz and Princess walk together |
| Burgundy           | Romance and depth                         |
| Silver-gray        | Elegance and balance                      |
| Heart and pin      | The destination is each other             |
| Wishes and prayers | The love and support of their guests      |

The look is derived from the couple's F&P logo: a high-contrast serif monogram, a compass at left, a globe at right, and an airplane trailing a swoosh between them. The site is minimal and refined. It avoids gold, bright colours, florals, heavy glow, and script fonts.
