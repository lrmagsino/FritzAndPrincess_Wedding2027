# 0001: Static export with managed services

**Status:** accepted

The invitation is hosted on GitHub Pages, which serves static files. Next.js `output: "export"` produces them. Guest names are read on the client, so one build serves every personalized URL. Wishes use the Supabase browser client with public-key-only access and Row Level Security; there is no custom app server. RSVP is a separate Google Form, not a website database.
